# Team photos

Drop founder headshots here. The home page references them from
`src/content/site/settings.md` (`founders[].photo`):

- `persefoni-noulika.jpg`
- `nick-sorros.jpg`

Use square images (~600×600, JPG or WebP). Until a file exists, the page
shows a coloured initials monogram instead of a broken image — the photo
appears automatically once the file is added (no code change needed).
